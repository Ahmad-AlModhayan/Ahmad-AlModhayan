# Ahmad AlModhayan

Software engineer and UX designer in Al Khobar, Saudi Arabia. I build Arabic-first, private-by-default software, and I spend my time on the parts most apps skip: working offline, right-to-left done properly, and data that stays with the person who owns it.

Someone who loves to learn and tea.

## What I'm building

- **A file-sync engine in Rust**: folder sync between Android, desktop and Google Drive, with encrypted vaults, conflict handling and a recovery bin.
- **An Arabic-first Android app in Kotlin and Jetpack Compose**: offline prayer times, the Madani Mushaf and khatmah planning. Released at 1.2.0.
- **A goals and focus planner in Flutter**, for Android and the web.
- **An AI testing tool in TypeScript** that records a verdict and evidence for every assertion it checks.
- **[Brief Coder](https://github.com/Ahmad-AlModhayan/brief-coder)**: an Obsidian plugin that runs, views and edits code in 40 languages. Open source, MIT.
